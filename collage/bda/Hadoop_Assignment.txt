1. Create a file “Sample” in a local file system and export it to the HDFS File System. 
=> hadoop fs -put D:\Sample.txt  /yash                                // here  /yash is directory name in Hadoop server


2. Write the HDFS command for copying a “Sample” file from HDFS to local File System.
=> hadoop fs -get   /yash/Sample.txt     D:/Sample.txt

3. Write HDFS commands for creating “Test” directory in HDFS and then removing that directory.
=> hadoop fs -mkdir /Test        // make Test Directory
=> hadoop fs -rmdir /Test        // remove Test Directory

4. Write HDFS command to display complete list of directories and files of HDFS.
=> hadoop fs -ls /

5. Write HDFS command for displaying the contents of “Sample” text file in HDFS on screen.
=> hadoop fs -cat  /yash/Sample.txt     // print data of Sample.txt in Console.

6. Write HDFS command for copying an existing “Sample” file in a “Test” HDFS directory to some another HDFS directory.
=> step - 1: make another directory name is  'Demo'
     hadoop fs -mkdir /Demo
=> step - 2 : copy file /yash  to Demo directory
     hadoop fs -put /yash/Sample.txt /Demo

7. Taking any data/file of your choice, execute the HDFS command for copying a given sample file in local file system to HDFS.
=>  hadoop  fd -copyFromLocal D:\Sample.txt /yash

8. Taking any data/file of your choice, execute the HDFS command for copying a given sample file in HDFS to local File System.
=>  hadoop  fd -copyToLocal /yash D:\Sample.txt

9. Execute the HDFS commands for creating some sample directory in HDFS and then removing that directory
=> hadoop fs -mkdir /Test        // make Test Directory
=> hadoop fs -rmdir /Test        // remove Test Directory
